# simplificacion_terminologia_medica_otros_anexos
# Materiales complementarios

En este repositorio se incluyen archivos correspondientes a tres cuestiones distintas del estudio:

1. **Corpus del estudio**
2. **Análisis cuantitativo estilométrico**
3. **Análisis de errores**

## 1. Corpus del estudio

En la carpeta `corpus` se proporciona el conjunto de datos principal del estudio en dos archivos JSON complementarios, que presentan dos tipos de estructuración diferentes según el criterio de organización de las definiciones:

* `corpus_por_modelo.json`
* `corpus_por_termino.json`

Además, el corpus se proporciona en otros dos formatos:

* **CSV**, para facilitar su procesamiento.
* **XLSX**, para facilitar su consulta y lectura.

## 2. Análisis cuantitativo estilométrico

En la carpeta `detalle_analisis_estadistico` se presentan los resultados del análisis cuantitativo estilométrico.

Los valores de los tests de **Friedman** y **Wilcoxon-Holm** están recogidos, además, en la sección de anexos de la memoria principal del TFM.

El archivo `resultados_descriptivos.csv` proporciona información adicional correspondiente a la estadística descriptiva, incluyendo:

* Mediana
* Cuartiles
* Mínimo
* Máximo

## 3. Análisis de errores

En la carpeta `análisis_errores` se proporciona un corpus en formato JSON anotado de acuerdo con el sistema de etiquetas planteado en este estudio.
